# WebImageZoom Library

The WebImageZoom library extends the capabilities of the standard WebImage control integrated in DataFlex, enabling images to be zoomed in and out, both via mouse, or using fingers on a mobile device.

There is a DataFlex Learning Center course available where the DataFlex WebImageZoom Library is demonstrated, including how to integrate the library into an application.

---

## Library Information

This repository contains a Library directory where the source for the WebImageZoom library is, and the Demo directory where you can find three versions (for DataFlex 23.0, 24.0 and 25.0) of a demo workspace that uses the library.
